## Специфика Claude Code

### Перед кодом
- Владелец переключает режим размышления перед реализацией. Поэтому: сначала
  исследование и объяснение, затем явная фраза «дальше будет код» — и ждать
  «делай / начинай / реализуй». Короткие правки в рамках уже согласованного
  шага этого не требуют.

### С чего начинать новую сессию
1. `docs/ROADMAP.md` — какой шаг следующий.
2. `docs/DECISIONS.md` — по теме шага (поиск по ключевым словам, файл большой).
3. Для квиза — `docs/QUIZ_NEON_HOT_PATH.md`.

### Project skills (`.claude/skills/`)
- `gamemind-copy` — тон и правила текстов интерфейса RU/EN; аудит текстов.
- `gamemind-questions` — как писать и проверять вопросы, формат партий.
- `gamemind-smoke` — локальная проверка горячего пути (Classic / Blitz /
  Survival / Daily) и прод-smoke после деплоя.

Сторонние skills из Cursor-периода (`.agents/skills/*` — Taste Skill,
`.cursor/skills/gamemind-taste-ui`) — справочно для текущего визуального
стиля; в фазе 4 их заменит `docs/DESIGN.md`.

### Проверки, которые обычно гоняем
- `npx tsc --noEmit -p tsconfig.json`
- `npm run lint`
- `npx vitest run`
- `npx next build` (перед этим `npm run dev:stop` — dev и build делят `.next`)
- браузер: встроенная панель, `http://localhost:3000`; мобильная ширина — preset `mobile`.

### Локальные данные
- dev-база ≠ прод. Тестовый игрок с ролью ADMIN есть **только в dev-БД**
  (данные — у владельца). На прод под чужим паролем не входим.
- Прод-логи: Vercel CLI 34 runtime-логи не отдаёт — просить владельца
  скопировать из Vercel → Logs.
