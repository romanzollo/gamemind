# GameMind — дизайн-система

Как выглядит интерфейс и по каким правилам добавлять новый. Источник
значений — `src/app/globals.css`; этот документ объясняет, **что** каждый
токен значит и **когда** его брать. Новый экран расширяет систему, а не
заводит свою.

Прежний документ периода Cursor (аудиты, промпты, журнал до ноября 2026) —
`docs/archive/TASTE_SKILL-2026.md`. Решения по экранам — `docs/redesign/`
и ADR в `docs/DECISIONS.md`.

---

## 1. Стиль: «табло»

Внутреннее имя — **Scoreboard Editorial**: спортивное табло и игровая
пресса. Чётко, соревновательно, без шума.

- **Да:** крупные цифры счёта, моноширинные метки, один акцент (бирюза),
  плотные понятные карточки, движение там, где есть событие (верно / мимо,
  отсчёт, новое достижение).
- **Нет:** фиолетовые SaaS-градиенты, неон и «казино», стекло и размытые
  пятна на фоне, эмодзи в интерфейсе, суп из одинаковых карточек,
  баннер на весь первый экран.
- **Игра — главное.** Бренд живёт в шапке; первый экран отвечает на
  «во что сыграть сейчас» (ADR «Home is the play hub»).

## 2. Жёсткие правила

1. Цвет — только токеном (`bg-surface`, `text-muted`…). Голый `#hex` в
   компоненте нельзя. Исключение — OG-картинка (`opengraph-image.tsx`):
   генератор не знает CSS-переменных.
2. Светлая и тёмная тема равноправны: новый токен — сразу в обеих.
3. Статус не только цветом: «верно / мимо» — ещё и словом или значком.
4. Текст интерфейса — из словарей RU + EN, тон — skill `gamemind-copy`.
5. Самый мелкий текст — `text-2xs` (11 px). Мельче не делаем.
6. Нажимаемое на телефоне — не меньше 44 px по высоте (`min-h-11`).
7. Любая анимация — через `motion-safe:` и гаснет при
   `prefers-reduced-motion` (общий блок в конце `globals.css`).
8. Картинка вопроса (IMAGE_GUESS) показывается целиком, без обрезки в 16:9.
9. Server Components по умолчанию; клиентский компонент — только ради
   состояния и событий.

## 3. Цвет

Семантика, а не оттенки: компонент говорит «поверхность» или «опасно»,
а не «серый 200». Значения обеих тем — в `globals.css`.

| Токен (Tailwind) | Что значит | Где |
|---|---|---|
| `background` | фон страницы | `body` |
| `surface` | карточка на странице | карточки режимов, таблицы, вопрос |
| `surface-muted` | плашка внутри карточки, неактивный чип | метки, бейджи, пустые ячейки |
| `surface-hover` | наведение на поверхность | строки, вторичные кнопки |
| `surface-raised` | поверх страницы | шторка, тосты |
| `foreground` | основной текст | |
| `muted` | второстепенный текст, подписи | метки над цифрами, пояснения |
| `border` | разделители и рамки | |
| `primary` / `primary-hover` / `primary-foreground` | акцент: главное действие, выбранный чип, фокус | «Начать», активная вкладка |
| `success` / `success-muted` | верно, рост | ответ «В точку», серия |
| `danger` / `danger-muted` | неверно, ошибка, удаление | «Мимо», ошибки форм |
| `warning` / `warning-muted` | внимание, не ошибка | «часы спешат», черновик |
| `info` / `info-muted` | нейтральная подсказка, ссылка | второстепенный акцент, не спорит с бирюзой |
| `ring` | обводка фокуса | `focus-visible:outline-ring` |
| `avatar-1…6` / `avatar-ink` | фон и фигура эмблемы-аватара | `UserAvatar` без фото |
| `podium-*` / `-fg` | медали топ‑3 и «Легенда» в рейтинге | |
| `tier-*` | редкость достижений (бронза → легенда) | рамка, значок, прогресс |

**Уровни поверхностей:** `background` → `surface` → `surface-raised`.
Чем «ближе» к игроку слой, тем он светлее в тёмной теме и тем заметнее
тень в светлой. Шаг между уровнями — около 5 единиц воспринимаемой
яркости (ΔL*); меньше — карточка сливается с фоном.

**Основные значения** (тёмная тема — «Графит», ADR «Graphite palette»):

| Токен | Светлая | Тёмная |
|---|---|---|
| `background` | `#eef1f4` | `#16191f` |
| `surface` | `#ffffff` | `#20242c` |
| `surface-muted` | `#e8edf2` | `#292e37` |
| `surface-raised` | `#ffffff` (+ тень) | `#2a2f39` |
| `border` | `#d3d9e1` | `#3a414d` |
| `foreground` / `muted` | `#14181f` / `#566170` | `#e8ecf1` / `#a3acb8` |
| `primary` | `#0b6e4f` | `#3ecf8e` |
| `success` / `danger` | `#1b7a3d` / `#c62828` | `#62d390` / `#f47e84` |

Новая палитра — сначала сравнение в `docs/redesign/` (как
`4.3f-palette.html`: экран продукта + таблица контраста), потом код.
Цвета OG-картинки (`opengraph-image.tsx`) — строками, обновлять вместе.

Прозрачные варианты (`bg-primary/10`, `border-success/30`) — допустимы
для подложек и рамок; новый цвет ими не изобретаем.

## 4. Шрифты и размеры

| Роль | Шрифт | Класс |
|---|---|---|
| Заголовки, крупные цифры, бренд | Oswald 500–700 | `font-display` |
| Текст, кнопки, вопросы | IBM Plex Sans 400–700 | `font-sans` (по умолчанию) |
| Счёт, таймеры, метки, id | IBM Plex Mono 400–600 | `font-mono` + `tabular-nums` для цифр |

Шрифты лежат у нас (`@fontsource`, `src/app/fonts.css`): Google Fonts из
России открывается не всегда.

**Шкала** (Tailwind + `text-2xs`):

| Класс | Размер | Для чего |
|---|---|---|
| `text-2xs` | 11 px | метки капсом, бейджи, подписи вкладок |
| `text-xs` | 12 px | подсказки под полями, мета-строки |
| `text-sm` | 14 px | основной текст интерфейса, кнопки |
| `text-base` | 16 px | текст вопроса, абзацы |
| `text-lg`–`text-2xl` | 18–24 px | заголовки секций и карточек |
| `text-3xl` и выше | 30 px+ | счёт на результате, отсчёт, цифры статистики |

**Метка-«надзаголовок»** (повторяющийся рецепт):
`font-mono text-2xs font-medium uppercase tracking-[0.14em] text-muted`.

Произвольные размеры `text-[…]` — только для цифр, подогнанных под ширину
(пример — `ProfileStatsSummary`), и с комментарием почему.

## 5. Отступы, скругления, тени

- Отступы — шаг Tailwind: 1 / 2 / 3 / 4 / 6 (4–24 px). Карточка — `p-4`
  на телефоне, `sm:p-6` шире; между карточками — `gap-3`.
- Поля страницы: `px-4` на телефоне, контент главной — `max-w-2xl`.
- Скругления: `rounded-sm` — бейджи и метки, `rounded-md` — кнопки и
  поля, `rounded-lg` — карточки, `rounded-full` — чипы, аватар,
  `rounded-t-2xl` — шторка.
- Тени: `shadow-sm` — карточка, `shadow-md` — тост, `shadow-lg` — шторка.
  В тёмной теме тени слабо видны — уровень там держит цвет поверхности.

## 6. Движение

Движение отвечает на событие, а не украшает. На экране вопроса — спокойно:
ничего не дёргается, пока игрок читает.

| Что | Как |
|---|---|
| Наведение, смена цвета | `motion-safe:transition-colors`, по умолчанию 150 мс |
| Появление, «прыжок» | кривая `ease-gm-out` |
| Отсчёт 3‑2‑1 | `motion-safe:animate-countdown-tick` |
| Значок нового достижения в тосте | `motion-safe:animate-achievement-pop` |
| Вспышка новой плитки достижения | `motion-safe:animate-achievement-glow` |

Новая анимация — `@keyframes gm-…` и токен `--animate-…` в `@theme`
(`globals.css`), а не длинный `animate-[…]` в разметке. Анимация не
начинается с `opacity: 0`: в фоновой вкладке кадры стоят, и элемент не
должен пропасть.

## 7. Компоненты (`src/shared/ui`)

| Компонент | Зачем |
|---|---|
| `Button`, `buttonClassName` | кнопки: `primary` (одно главное действие на экране), `secondary`, `ghost`, `danger`; ссылка-кнопка — через `buttonClassName` |
| `SubmitButton` | кнопка формы с состоянием «работаю» (`aria-busy`) |
| `PendingLink`, `PendingSpinner` | переход с откликом на медленной сети |
| `ChipRadioGroup` | выбор чипами (сложность, тема, число вопросов); поддерживает недоступный вариант |
| `BottomSheet` | шторка настроек режима (`<dialog>`), на широком экране — окно |
| `InlineAlert` | сообщение рядом с действием (ошибка старта и т. п.) |
| `toastSuccess` / `toastError` / `toastInfo` | короткий отклик после действия |
| `EmptyState`, `Skeleton`, `StatusPage` | пусто, загрузка, ошибка / 404 |
| `SiteHeader`, `SiteTabBar` | шапка и нижняя панель «Играть / Рейтинг / Профиль» |
| `UserAvatar` | аватар игрока |
| `answerOptionClassName`, `answerVerdictClassName` | вид варианта ответа и плашки «В точку! / Мимо» — общий для игры и демо-вопроса |
| `GameMindMark` | знак в шапке |

**Состояния**, которые есть у каждого интерактивного элемента:

| Состояние | Как выглядит |
|---|---|
| обычное | токены компонента |
| наведение | `hover:bg-surface-hover` (вторичные) или `hover:bg-primary-hover` |
| фокус с клавиатуры | `focus-visible:outline-2 outline-ring`, со смещением |
| выбран | `primary` фон / рамка |
| недоступно | `disabled:opacity-50 cursor-not-allowed`; у чипа — пунктир |
| ждёт ответа сервера | `aria-busy`, текст «Секунду…» или спиннер; повторное нажатие не шлёт запрос |
| ошибка | `danger` + текст, что делать дальше |

**Аватар без фото — эмблема.** Тон (`avatar-1…6`), фигура (шевроны, дуга,
столбики, шашечки) и поворот выбираются по id игрока
(`getAvatarPattern`, `src/shared/ui/avatar-pattern.ts`) — 96 вариантов.
Сервер передаёт в `UserAvatar` только номер варианта, не id; в БД
ничего не хранится, у гостя после регистрации эмблема та же. Битая
ссылка на фото — тоже эмблема.

Компонент, нужный двум фичам, переезжает в `src/shared/ui`; нужный одной —
живёт в своей фиче.

## 8. Как проверить вид

- Телефон 375 px (встроенная панель, preset `mobile`) и широкий экран.
- Обе темы: переключатель в шапке.
- Горизонтальной прокрутки нет, ничего не обрезано на 320 px.
- Контраст текста — WCAG AA (4.5:1, крупный — 3:1).
- Reduced motion: анимации гаснут, интерфейс работает.
