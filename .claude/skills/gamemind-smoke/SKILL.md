# Smoke горячего пути

Канон правил — `docs/QUIZ_NEON_HOT_PATH.md`. Этот skill — **как проверить руками
или браузером**, что ничего не сломалось.

## Подготовка (локально)

1. `npm run dev` (скрипт сам гасит старый dev). Первая загрузка страниц в dev
   медленная (Neon + TLS на Windows: 2–10 с на hop) — это не баг прода.
2. Войти тестовым игроком dev-БД (роль ADMIN есть только в dev; учётные
   данные — у владельца, в ответах их не повторять).
3. Если меняли роль в БД — перелогиниться: proxy читает роль из JWT.

## Матрица (минимум перед коммитом изменений горячего пути)

| Режим | Что сделать | Что должно быть |
|---|---|---|
| Классика (Легко, 3) | ответить на все → «Завершить» | `/result/<id>`, очки, разбор подгрузился |
| Блиц MIX | ответить на часть → дождаться 00:00 | автоотправка, `/result/<id>?clock=1`, плашка «Время вышло» |
| Блиц MIX | ответить на все → «Завершить» до 00:00 | `/result/<id>` **без** `clock=1` |
| Выживание | 1 верный ответ → дождаться нуля в банке | `/result/<id>?wave=cut`, очки забега > 0 |
| Челлендж дня | ответить на все → «Завершить» | результат + тосты достижений |

Проверка Выживания по БД (только чтение): у последней волны
`survivalClockOk = true`, `SurvivalRun.totalScore` вырос.

Полезно: `document.querySelector('[aria-live=polite]')` — текст таймера;
правильный вариант Выживания есть в props React (DTO отдаёт `isCorrect`).

## Что смотреть в логе dev

- `⨯` / `unhandled` — необработанная ошибка (не должно быть).
- `Direct pg hop … phase=connect … timeout` — флейк dev-сети; сдача должна
  вернуть `SUBMIT_FAILED` с кнопкой повтора, а не страницу ошибки.

## Автоматический smoke (Playwright)

- Локально: `npm run dev`, затем `npm run test:e2e` — Классика 3 + Блиц MIX
  под dev smoke-игроком (`gm_smoke`, данные в `.env`, скрыт из рейтингов).
  Это быстрый первый прогон перед ручной матрицей, а не её замена.
- Селекторы — `data-testid` (`login-form`, `classic-setup`, `blitz-setup`,
  `quiz-submit`, `quiz-result-score`) и роль `radiogroup`. Переименовал
  testid или переделал форму — поправь `e2e/` в том же коммите.

## Прод после деплоя (www.game-mind.ru)

Классику 3 и Блиц MIX после каждого прод-деплоя играет workflow
**Prod smoke** (GitHub Actions, ждёт sha деплоя на `/api/version`). Красный
прогон — смотреть шаг и скриншоты в артефакте, ошибку — в Sentry.
Руками остаётся: Выживание (если трогали — одна волна до нуля в банке) и
Челлендж дня. Делает владелец (на прод под его паролем ИИ не входит);
логи — из Vercel → Logs.

## Браузер (встроенная панель)

- Если панель скрыта, анимации и таймеры троттлятся (единицы кадров в
  секунду) — замеры анимаций недостоверны, логика всё равно проверяема.
- Мобильная ширина: `resize_window` preset `mobile`, после — `desktop`.
